## 🏗️ Instalación y Desarrollo Local

```bash
# Clona el repositorio
git clone https://github.com/rodrigopsimoes/mi-portifolio.git
cd mi-portifolio

# Instala dependencias
npm install

# Inicia el servidor de desarrollo
npm run dev
```

El servidor estará disponible en `http://localhost:5173`

---

## 📦 Build de Producción

```bash
npm run build
# Los archivos compilados se generan en la carpeta /dist
```

## 🚀 Despliegue

El proyecto se despliega automáticamente en **GitHub Pages** en cada push a la rama `main`, mediante GitHub Actions.
